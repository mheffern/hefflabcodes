Files & samples

Each file is listed under the run it belongs to. Files with the same run name are merged, so an ICP-MS file and a DAD file from one injection become one run; rename a file's run to pair them. Runs that share a biological sample are technical replicates; different biological samples within a type are biological replicates. Edits are remembered in this browser.

Recognized automatically: Agilent ICP-MS “Intensity Vs Time” exports, Agilent DAD signal exports (one block per wavelength), BatchLog.csv and sample_sheet.csv. Anything else opens the import editor, where you can set the layout once and save it as a format.

Panels & offsets

Choose what is stacked in each panel and how each trace is scaled. A panel with several signals colours by signal (runs differ by dash). % of max scales each trace so its own tallest point is 100; × factor multiplies; shift moves a trace up or down.

Detector time offsets

Seconds added to every time point of that detector, to line up detectors plumbed in series (e.g. DAD before ICP-MS). Positive moves its peaks later.
